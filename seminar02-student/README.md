# Семинар 2: линейная модель

Распакуйте архив целиком и запустите:

```bash
uv run --python 3.12 --with-requirements requirements.txt jupyter lab
```

Откройте `notebooks/seminar.ipynb`. Рядом уже находятся `course_support.py`,
`requirements.txt`, паспорт данных и два необходимых CSV. Архив не содержит
test-набор, ответы или преподавательские заметки. Интернет для notebook не нужен;
все данные синтетические, достаточно CPU.
