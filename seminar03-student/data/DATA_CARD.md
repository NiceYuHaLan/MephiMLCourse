## Преобразования этого комплекта

К исходной таблице добавлен row_id (исходная позиция строки, 0–397).
Все 398 строк распределены между train/validation/test, ни один исходный ответ не изменён.
Пропуски horsepower сохранены: всего шесть. В preprocessing они заполняются медианой только fit-части.
Масштабы также оцениваются только по fit-части. Не добавлялись шум, копии строк или искусственная задержка вычислений.

Test: 80 строк, `train_test_split(..., test_size=80, random_state=17)`.
Из остальных 318 строк validation: 80, `random_state=29`.
Остаток train: 238 строк. Разбиение не стратифицировано и зафиксировано до экспериментального выбора.
В каждой части имеются оба класса по событию mpg < 20.
Файлы разбиений скопированы из исходного комплекта без изменения байтов. Восстанавливать разбиение для занятия не требуется; скрипт подготовки в сокращённый архив не включён.

## Поля

| Поле | Значение | Использование |
|---|---|---|
| row_id | Позиция в исходном CSV | Аудит разбиений, не признак |
| mpg | Экономичность: мили на галлон, city cycle | Регрессионный ответ |
| weight | Масса автомобиля, фунты | Признак |
| horsepower | Мощность | Признак; есть пропуски |
| model_year | Модельный год в двузначной записи, 70–82 | Признак; исторические данные |
| cylinders | Число цилиндров | Сохранено, не входит в модели семинара |
| displacement | Рабочий объём двигателя | Сохранено, не входит в модели семинара |
| acceleration | Показатель разгона в исходной таблице | Сохранено, не используется |
| origin | Происхождение, строковое кодирование зеркала | Сохранено, не используется |
| name | Название автомобиля | Сохранено, не используется |

Не требуется разбирать категории, нормализовать названия или запоминать систему единиц двигателя.
Три рабочих признака — намеренное упрощение обучения, не утверждение об оптимальном полном наборе.

## Классификация и ограничения

Y=1, когда **mpg < 20**; при равенстве 20 Y=0.
20 mpg — выбранная заранее учебная граница, а не реальная регуляторная/инженерная норма.
Стоимость FP=1, FN=4 — условные учебные цены, верные решения считаются бесплатными.
Обнаружение события и изменение физической экономичности автомобиля — разные задачи.

Считается, что масса, мощность и год известны до получения целевого измерения mpg.
Само mpg, его преобразования и бинарная метка запрещены во входных признаках классификатора.

Случайный K-fold используется как учебная оценка переноса на другие строки той же исторической смеси.
Независимость строк не доказана: есть родственные модели и изменения по годам.
Результат не выдаётся за проверку будущих лет, новых производителей или причинного эффекта массы.
Для таких задач требуется другая схема разделения, определённая целью применения.

Test-файл технически доступен для воспроизводимости, но открывается только после фиксации обоих решений.
Семинар не реализует защиту ответов от студентов и не используется как конкурс на test.


## Сохранённый эксперимент B04D

`cv_k_reference.csv` — готовая таблица из первоначального комплекта, не новые измерения.
Модель `linear`, три рабочих признака, seed=17; каждый K запускает полную CV с предобработкой внутри неё.
Условия замера: n_jobs=1, BLAS threads=1; время включает полный вызов CV, но не чтение данных и рисование.
Версии исходного замера: Python 3.13.5, numpy 2.3.5, pandas 2.2.3, scikit-learn 1.8.0, matplotlib 3.10.8.
Это иллюстрация цены проверки в одном окружении, не сравнение компьютеров и не гарантия улучшения MAE.
Демонстрационный ряд K: 3, 4, 5, 8, 13, 21, 34, 55, 88, 141, 226, 238. Студенты не реализуют планировщик.
