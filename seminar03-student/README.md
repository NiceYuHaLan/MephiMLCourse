# Семинар 3: маршрут A

Распакуйте весь архив. Из его корня выполните:

```bash
uv run --python 3.12 --with-requirements requirements.txt jupyter lab notebooks/seminar.ipynb
```

Полное условие — seminar.md; SOURCES.md и data/DATA_CARD.md описывают происхождение.
Данные Auto MPG локальны; после установки окружения сеть не нужна. Test с ответами
доступен для финальной проверки в B15 после фиксации обоих решений; не настраивайте
по нему модель или порог. Незавершённые функции сообщают об этом явно.
